# WriteUp Chunker

A simple React + Vite tool that splits pasted document text into copy-ready chunks.

## Features
- Paste the full document directly — no file upload required.
- Default limit: 3,000 words per copy.
- Change the word limit if needed.
- Preserves the original wording.
- Keeps paragraphs together when possible.
- Copies individual chunks or all chunks.
- Download all chunks as a TXT file.
- Word counts for the full document and every chunk.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
